# Лабораторная работа №1 — консольный генератор билетов

Запрашивает фамилию и имя, выдаёт случайный билет 1–20 и сразу дописывает строку в `journal.xlsx`. ESC — выход.

## Файлы
- `main.py` — точка входа, главный цикл
- `console_input.py` — посимвольный ввод (ESC / Enter / Backspace) через `msvcrt`
- `journal.py` — запись в Excel, генерация номера
- `tests/test_lab1.py` — unit-тесты (pytest)

## Запуск (Windows, PowerShell или терминал VS Code)
```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```
Важно: запускать в **PowerShell / cmd / терминале VS Code**. В Git Bash (mintty) ESC и посимвольный ввод работают некорректно.

## Тесты
```
python -m pytest -v
```

## Как выполнены требования
- **Сохранение после каждой записи** — `append_record` открывает, дописывает и сохраняет файл для каждого студента.
- **Проверка ввода** — пустая строка или одни пробелы → запрос повторяется; пробелы по краям обрезаются.
- **Файл открыт в Excel** — сообщение «закройте файл и нажмите Enter», затем повтор попытки.
- **ESC** — ввод читается посимвольно, поэтому ESC срабатывает в любой момент ожидания ввода.
